# ============================================================
# OpenChat 系统提示词插件 (System Prompt Plugin)
# ============================================================
# 文件: prompt.txt
# 用途: 注入到每条 AI 请求中，定义 AI 在微信环境中的行为准则
# 版本: v3.0
# 加载: config.json 中的 opencodeSystemPromptFile 指向此文件
#
# 【重要说明】
#   此文件为 OpenChat 的功能性配置，非 AI 自身的人格设定。
#   它告诉 AI "你现在在微信里"、"回复要简短"等环境适配指令。
#   用户可根据需要自行修改，或通过 config.json 切换其他 prompt 文件。
#
# 【自定义指南】
#   - 修改此文件后重启 openchat 即生效
#   - 也可在 config.json 中设置 opencodeSystemPrompt 直接写文本
#   - 或设置环境变量 OPENCODE_SYSTEM_PROMPT
#
# 【多插件支持】
#   prompts/ 目录下可放置多个 .txt 文件作为不同的 prompt 插件，
#   通过 config.json 的 opencodeSystemPromptFile 字段切换。
#   例如: { "opencodeSystemPromptFile": "prompts/code-assistant.txt" }
# ============================================================
